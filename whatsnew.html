What’s New

Beta channel

Version 5.2.4

  • Allarise is now free. Every feature is unlocked for everyone; purchases became an optional tip jar. Existing purchasers and early adopters keep everything and are never prompted.
  • Slept Through Today. The app tallies alarms that rang ten minutes with no dismiss or snooze, resets at local midnight, and catches up even if you never open the app. The integration (3.4.0+) exposes it as a Home Assistant dashboard sensor with an alarms attribute.
  • Automatic alarm consolidation. When you’ve slept through a set of alarms, missions consolidate into one set instead of stacking, notes merge into one page, and sleep sounds stop for good when an alarm fires instead of resuming after snooze.
  • App Persistence went three-way. New Dynamic mode keeps the app awake only while charging or near an alarm, with a one-time notice explaining it to existing installs.
  • Custom accent colors. Pick an accent per theme and per light/dark appearance; it applies app-wide.
  • HA alert media fixes. Images now load from plain-http Home Assistant hosts, and video failures are surfaced instead of silent.
